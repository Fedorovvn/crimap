# Budapest Signal — тест-кейсы первой версии

## Автоматически после каждой правки

Запуск: `pnpm test`.

| ID | Элемент | Шаг | Ожидаемый результат |
|---|---|---|---|
| A-01 | Фильтр периода | Выбрать 24 ч / 7 дней / месяц | В ленте и на карте остаются только события выбранного периода. |
| A-02 | Безопасный выбор карточки | Выбрать событие, затем сузить период | Если событие исчезло из выборки, открывается первое оставшееся; ошибки нет. |
| A-03 | Пустой результат | Выбрать 24 ч при текущих двух seed‑записях | Видно понятное empty state; досье события не остаётся на экране. |
| A-04 | Координаты точек | Загрузить события с широтой и долготой | Маркеры получают координаты из записи, а не процентное положение в интерфейсе. |
| A-05 | Лента и карта | Нажать точку Akácfa | Открывается её статус, summary и обновление, не данные Soroksári. |
| A-06 | Источник | Открыть Soroksári | В карточке есть кликабельный официальный источник BRFK с корректным URL. |
| A-07 | Пустая база | Передать в UI пустой набор | Карта и empty state рендерятся без падения. |

## Browser QA перед публикацией

| ID | Элемент | Шаг | Ожидаемый результат |
|---|---|---|---|
| B-01 | Шапка | Открыть сайт на 375px и 1440px | Лого и RU видны; навигация не перекрывает контент; горизонтального скролла нет. |
| B-02 | Навигация | Нажать «Происшествия» | Переход к секции `#incidents`. «События» и «Транспорт» честно отмечены как будущие разделы и не выглядят как рабочие ссылки. |
| B-03 | Язык | Проверить RU / EN / HU | RU показан как активный. EN/HU пока не являются переключателями — зафиксировать как незавершённую функцию, не как дефект. |
| B-04 | Фильтр периода | Кликнуть 24 ч, 7 дней, месяц; пройти Tab и Enter | Выбор меняет данные, `aria-pressed` указывает активный период, управление доступно с клавиатуры. |
| B-05 | Карта | Проверить загрузку OpenStreetMap | Карта не перекрывает точки; есть подпись OpenStreetMap; при недоступности внешнего слоя точки и лента остаются рабочими. |
| B-06 | Геопривязка | Увеличить, уменьшить и сдвинуть карту | Каждая точка остаётся над своей географической координатой, не сдвигается относительно улиц. |
| B-07 | Точка карты | Нажать каждую из точек | Каждая точка открывает именно своё досье: название, район, статус, хронологию и источники. |
| B-08 | Лента | Нажать каждую карточку | Выбранная карточка визуально выделяется, справа открываются её данные. |
| B-09 | Досье | Сверить статус, district, location precision, summary | Данные совпадают с записью D1; нет неподтверждённых подробностей без отдельной метки. |
| B-10 | AI review | Открыть каждое досье | Текст объясняет, что это сводка проверенных фактов, а не источник или судебный вывод. |
| B-11 | Хронология | Проверить порядок дат | Обновления идут от раннего к позднему; каждая запись имеет время и уровень достоверности. |
| B-12 | Источники | Открыть каждую ссылку | Ссылка ведёт на указанный материал police.hu в новой вкладке; не открывает пустую или нерелевантную страницу. |
| B-13 | Чувствительный контент | Проверить блок фото | Сайт не показывает не лицензированное/шоковое фото; видно объяснение, что материал доступен только у первоисточника. |
| B-14 | Empty state | На 24 ч получить ноль результатов | Нет устаревшего выбранного досье, вместо него корректное сообщение. |
| B-15 | Адаптив | 375px, 768px, 1440px | Карта, лента и досье остаются читаемыми, кнопки не меньше 44px, текст не обрезан. |
| B-16 | Доступность | Пройти всю страницу Tab / Shift+Tab | Видимый focus; порядок: фильтр → точки → карточки → источники; все интерактивные элементы имеют доступное имя. |

## Данные и публикация

| ID | Что проверяем | Шаг | Ожидаемый результат |
|---|---|---|---|
| D-01 | Миграция D1 | Развернуть новую версию | В базе существуют `incidents`, `incident_sources`, `incident_updates` и заявленные индексы. |
| D-02 | Seed‑данные | Открыть сайт впервые после чистого развёртывания | В D1 добавляются ровно две стартовые истории, их источники и обновления. Повторное открытие не создаёт дублей. |
