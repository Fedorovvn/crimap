# Budapest Signal — локальная версия

Откройте `Start-Budapest-Signal.cmd` двойным щелчком. Он запустит сайт в фоне и откроет браузер.

Адрес: http://127.0.0.1:5173

Исходники, оформление и база данных восстановлены из предоставленного архива. Применено включённое в проект обновление базы `0001`, добавляющее таблицу фотографий. Для Windows выбран локальный режим `portable`. Используется Node.js из установленного окружения Codex; системный Node.js 20 для этого проекта слишком старый.

Локальные изменения сохраняются в этой папке. Данные находятся в `.wrangler/state`, журналы запуска — в `.sites-runtime/local-server.log` и `.sites-runtime/local-server-error.log`.

Сайт содержит данные из архива. Карта и внешние фотографии загружаются из интернета.

Добавлена миграция `0003_incident_context` для сведений и версий с отдельными источниками. В текущей локальной базе она уже применена. При переносе на новую базу примените все миграции из `drizzle` до запуска. Дополнительные сообщения СМИ проверены по публикациям и показаны как неподтверждённые; генерация гипотез моделью пока не подключена.

Для разработки с подходящим Node.js: `pnpm dev`. Проверки проекта: `pnpm test`. Зависимости устанавливаются через `pnpm install --frozen-lockfile`.
