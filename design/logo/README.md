Sources were created with the built-in image tool from the user-provided screenshot. The accepted main image uses a coral rounded diamond with a soft glow on a warm charcoal schematic map. Browser edit prompt: enlarge only the rounded diamond to nearly fill the square, preserving shape, color and glow. Header edit prompt: extract the diamond and glow onto genuine transparent alpha, removing only the map.

Raster size exports use ImageMagick Lanczos resizing. New asset URLs avoid cached earlier logo designs. Do not substitute older SVG reconstructions. Visual redesigns must be previewed and approved before deployment.
