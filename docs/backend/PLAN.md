# План backend Crimap

Дата: 26 сентября 2026. План выполняется последовательно; результат каждого этапа хранится в этом репозитории.

1. **Контракт и сверка интерфейса — в работе.** Проверить опубликованные карточки и типы React/БД; описать фото, бэджи, участников, ориентировки, версии, правовую информацию, ссылки, переводы и неизвестные значения. Сохранить совместимость текущего отображения и добавить проверяемый контракт сбора с доказательствами.
2. **Архитектура — далее.** Разделить обнаружение публикаций и повторные проверки событий; перенести все возрастные интервалы; определить хранение оригиналов, объединение событий, переводы EN→RU, HU-оригиналы, бюджет и места вызовов моделей.
3. **Инструкции DeepSeek — далее.** Отдельные инструкции извлечения, уточнения через инструменты и перевода. Неизвестное не угадывается, оригинальные цитаты и источники сохраняются; предположения и юридические оценки имеют отдельный статус.
4. **Реализация и проверка — далее.** Постоянная очередь SQLite, сбор RSS/HTML, инструменты поиска/чтения, DeepSeek, дедупликация, публикация в существующие таблицы, журнал расходов, CLI, служба VPS и тесты. Проверить на фикстурах и доступных реальных источниках; синхронизировать локально, GitHub и сервер.

## Уже найденные расхождения

- Старые документы контракта лежали вне Git; перенесены в `contracts/v1/` как исходный снимок.
- В старом контракте нет `wantedNotice`; UI уже поддерживает описание ориентировки и ссылку.
- Категории и сигналы UI выводятся из русского текста; новый сбор должен хранить явные коды.
- Фильтр карты использует фиксированное время демонстрации — для рабочих данных нужен текущий момент.
- Фото и ссылки в карточке — отдельные поля; наличие источника не доказывает право копировать фотографию.
- Роль подозреваемого, процессуальный статус и состояние пострадавшего различаются.
- Группы отображаются от пяти человек; меньшие группы должны раскрываться без выдумывания личностей.
- EN/RU сейчас не являются полноценными языковыми версиями интерфейса. Backend будет хранить редакционную EN-версию, RU-перевод и оригинальные HU-документы; это не означает готовую локализацию всего интерфейса.

## Внешние зависимости

- Получен секрет для проверки DeepSeek; он не должен попадать в Git, документы или логи.
- Ключ внешнего поискового API пока не предоставлен. Сбор прямых источников и чтение страниц могут работать независимо; подключение поиска задаётся конфигурацией.
- Платные обращения ограничиваются явным бюджетом и журналом; отсутствие ключа/баланса показывается как состояние, а не успешная обработка.
