# План backend Crimap

Дата: 26 сентября 2026. План выполняется последовательно; результат каждого этапа хранится в этом репозитории.

1. **Контракт и сверка интерфейса — готово.** Поля проверены по опубликованным карточкам и типам React/БД. Контракт 2.0 и JSON Schema находятся в Git, включая фото, бэджи, ориентировки, контекст, право, цитаты и переводы. Совместимость публичных карточек сохранена.
2. **Архитектура — готово.** Описаны обнаружение публикаций, объединение, все согласованные интервалы, версии HU/EN/RU, бюджет и места вызовов моделей. См. ARCHITECTURE.md.
3. **Инструкции DeepSeek — готово.** Инструкции: короткий отбор, извлечение, объединение, план поиска, выбор фото, перевод, финальная проверка и исправление. По дополнительной просьбе владельца Flash обрабатывает данные, Pro проверяет готовую редакцию; обе модели могут предлагать новые поля/типы в отдельный файл.
4. **Реализация и проверка — готово для запуска с редакционной публикацией.** Постоянная очередь SQLite, RSS/HTML, поисковый адаптер, DeepSeek, дедупликация, публикация в существующую БД, расходы, CLI и systemd установлены. Прямой сбор запущен на VPS, сайт отвечает HTTP 200. Расширенный поиск ждёт ключ Brave; это не мешает прямым источникам.

## Результаты проверки

- Тесты backend (включая media evidence), 30 тестов существующего интерфейса и тест SQLite-обвязки — проходят.
- Проверка TypeScript и production-сборка выполнены; backend-тесты также прошли на Ubuntu VPS.
- Прямые ленты BRFK, OKF, Kékvillogó доступны (на момент проверки: 10, 2, 20 элементов).
- На настоящей статье police.hu проверены извлечение EN, RU-перевод и проверка Pro. Pro вернул неточный перевод на исправление; черновик не опубликован.
- После обновления проверена страница crimap.online в браузере; существующие две карточки и их источники сохранены.
- Ключ хранится вне Git с правами 0640, дневной лимит обычного сбора $0.50, общий лимит разового архивного обхода $5. Числа расходов являются консервативной оценкой, не счётом провайдера.

## Границы текущего запуска

Автоматические сбор и проверка создают черновики. Публикация требует положительной проверки текущей редакции, даты, проверенных координат и редакционного решения. Защищённый редактор доступен на `/admin/`; автогеокодирование Photon, выбор фото из источников и исправления Flash подключены. Архивный обход имеет отдельный общий потолок $5 и показывает охват в редакторе. BKK/соцсети и остальные источники без RSS требуют отдельного адаптера; каталог не равен 33 работающим интеграциям. Публичный интерфейс доступен на RU/EN/HU; Flash подготавливает переводы карточек перед финальной проверкой.

## Уже найденные расхождения

- Старые документы контракта лежали вне Git; перенесены в `contracts/v1/` как исходный снимок.
- В старом контракте нет `wantedNotice`; UI уже поддерживает описание ориентировки и ссылку.
- Категории и сигналы UI выводятся из русского текста; новый сбор должен хранить явные коды.
- Фильтр карты использует фиксированное время демонстрации — для рабочих данных нужен текущий момент.
- Фото и ссылки в карточке — отдельные поля; наличие источника не доказывает право копировать фотографию.
- Роль подозреваемого, процессуальный статус и состояние пострадавшего различаются.
- Группы отображаются от пяти человек; меньшие группы должны раскрываться без выдумывания личностей.
- Редакционная EN-версия, RU-перевод и оригинальные HU-документы хранятся раздельно. Публичный интерфейс RU/EN/HU использует проверенные словари отображения текущей редакции.

## Внешние зависимости

- Получен секрет для проверки DeepSeek; он не должен попадать в Git, документы или логи.
- Ключ внешнего поискового API пока не предоставлен. Сбор прямых источников и чтение страниц могут работать независимо; подключение поиска задаётся конфигурацией.
- Платные обращения ограничиваются явным бюджетом и журналом; отсутствие ключа/баланса показывается как состояние, а не успешная обработка.
